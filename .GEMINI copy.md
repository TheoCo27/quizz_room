# Design System & Architecture Frontend - ft_transcendence (Cyberpunk)

En tant qu'expert UI/UX et développeur frontend, voici la proposition architecturale et technique pour le frontend de `ft_transcendence` avec une direction artistique **Cyberpunk** prononcée, en utilisant **React** et **Tailwind CSS** (stack déjà en place dans le projet).

## 1. Architecture des Répertoires du Frontend

L'architecture est pensée pour être scalable, modulaire et prête à accueillir les modules optionnels (i18n, statistiques, succès).

```text
frontend/
├── src/
│   ├── assets/                 # Ressources statiques (images, polices monospace, sons)
│   ├── components/             # Composants réutilisables
│   │   ├── cyber/              # ✨ Design System Cyberpunk (Boutons, Inputs, Glitch text, etc.)
│   │   ├── game/               # Composants spécifiques au jeu (Canvas, Scoreboard)
│   │   ├── layout/             # Composants de mise en page (Navbar, Footer, Sidebar)
│   │   └── social/             # Composants sociaux (Chat, Liste d'amis, Notifications)
│   ├── contexts/               # Contextes React (Thème, Auth, WebSocket, i18n)
│   ├── hooks/                  # Hooks personnalisés (useAuth, useGame, useChat)
│   ├── i18n/                   # 🌐 Fichiers de traduction (Anticipation)
│   ├── pages/                  # Vues de l'application
│   │   ├── auth/               # Login, Inscription
│   │   ├── game/               # Plateforme de jeu
│   │   ├── legal/              # Privacy, TOS
│   │   └── profile/            # Profil utilisateur, Statistiques, Succès
│   ├── services/               # Appels API (Axios/Fetch), gestion WebSocket
│   ├── store/                  # Gestion d'état global (MobX, comme vu dans package.json)
│   ├── styles/                 # CSS global, animations clés (glitch, neon)
│   ├── types/                  # Définitions TypeScript globales
│   ├── utils/                  # Fonctions utilitaires (formatage, validation)
│   ├── App.tsx                 # Composant racine (Routing, Providers)
│   └── main.tsx                # Point d'entrée React
```

## 2. Design System : Le Bouton Cyberpunk (`CyberButton`)

Ce composant utilise **React** et **Tailwind CSS**. Il intègre un effet "glitch" au survol, des couleurs néon (cyan/magenta) et un aspect "terminal" / tech-wear.

**Fichier : `src/components/cyber/CyberButton.tsx`**

```tsx
import React from 'react';

interface CyberButtonProps extends React.ButtonHTMLAttributes<HTMLButtonElement> {
  variant?: 'primary' | 'secondary' | 'danger';
  glitchText?: string;
}

export const CyberButton: React.FC<CyberButtonProps> = ({ 
  children, 
  variant = 'primary', 
  glitchText,
  className = '',
  ...props 
}) => {
  const baseStyle = "relative inline-block font-mono uppercase font-bold tracking-widest text-sm py-3 px-8 transition-all duration-300 overflow-hidden group focus:outline-none focus:ring-2 focus:ring-offset-2 focus:ring-offset-black";
  
  const variants = {
    primary: "bg-transparent text-cyan-400 border-2 border-cyan-400 hover:bg-cyan-400 hover:text-black hover:shadow-[0_0_15px_rgba(34,211,238,0.7)] focus:ring-cyan-400",
    secondary: "bg-transparent text-magenta-500 border-2 border-magenta-500 hover:bg-magenta-500 hover:text-black hover:shadow-[0_0_15px_rgba(217,70,239,0.7)] focus:ring-magenta-500",
    danger: "bg-transparent text-red-500 border-2 border-red-500 hover:bg-red-500 hover:text-black hover:shadow-[0_0_15px_rgba(239,68,68,0.7)] focus:ring-red-500"
  };

  return (
    <button 
      className={`${baseStyle} ${variants[variant]} ${className}`}
      {...props}
    >
      {/* Effet d'arrière-plan scanline */}
      <span className="absolute inset-0 w-full h-full bg-[linear-gradient(transparent_50%,rgba(0,0,0,0.1)_50%)] bg-[length:100%_4px] opacity-0 group-hover:opacity-100 transition-opacity"></span>
      
      {/* Coin coupé (Tech-wear aesthetic) */}
      <span className="absolute bottom-0 right-0 w-3 h-3 bg-black transform rotate-45 translate-x-1.5 translate-y-1.5 border-t-2 border-l-2 border-transparent group-hover:border-current"></span>

      {/* Texte principal */}
      <span className="relative z-10 block group-hover:animate-pulse">
        {children}
      </span>

      {/* Texte Glitch (visible uniquement au survol si défini) */}
      {glitchText && (
        <span className="absolute inset-0 z-20 flex items-center justify-center font-bold opacity-0 group-hover:opacity-100 group-hover:animate-[glitch_0.2s_linear_infinite] mix-blend-difference text-white pointer-events-none" aria-hidden="true">
          {glitchText}
        </span>
      )}
    </button>
  );
};
```

*(Note : Pour que l'animation `glitch` fonctionne parfaitement, vous pouvez ajouter une keyframe custom dans Tailwind ou dans votre `styles.css` global).*

## 3. Structure de la Page de Profil Utilisateur

La page de profil doit ressembler à un "Dossier Personnel" d'une corporation dystopique, affiché sur un terminal de sécurité.

**Vue : `src/pages/profile/ProfilePage.tsx`**

### Layout Principal :
- **Background :** Noir profond (#050505) avec une légère grille de fond (`grid-pattern`) cyan très foncée.
- **Header "Terminal" :** Affiche l'ID unique de l'utilisateur, son rôle, et l'heure système en temps réel.

### Sections de la page :

1. **Carte d'Identité (ID Card) :**
   - **Avatar :** Bordures néon, avec un bouton "Upload" style hacker.
   - **Informations :** Pseudo (modifiable), Email (masqué partiellement `c***@corp.com`), Statut (En ligne/En jeu/Hors ligne).
   - **Bouton d'Action :** `CyberButton` pour "Mettre à jour l'ID" ou "Activer 2FA".

2. **Dossier de Combat (Statistiques & Historique) - *Module Anticipé* :**
   - **Graphiques Radars / Barres :** Winrate, Matchs joués, Temps de jeu. Affichés avec des barres de progression au style terminal de chargement (`[||||||----] 60%`).
   - **Historique des Matchs :** Un tableau défilant type "Logs système", listant les derniers adversaires, les scores (en vert pour la victoire, rouge pour la défaite) et la date.

3. **Accréditations (Gamification / Succès) - *Module Anticipé* :**
   - Grille affichant des "Badges" sous forme d'icônes vectorielles abstraites. Les succès non débloqués sont grisés avec un effet de "données corrompues" (glitch).
   - Barre d'expérience (XP) globale.

4. **Interactions Sociales :**
   - Section latérale (Sidebar) rétractable contenant la **Liste d'Amis**.
   - Indicateurs de statut avec des LEDs néon (🟢 Cyan = Dispo, 🔴 Rouge = Ne pas déranger, 🟣 Magenta = En jeu).
   - Bouton pour ouvrir un "Canal de communication crypté" (Chat privé).

### Validation et Accessibilité :
- Tous les formulaires de mise à jour (pseudo, mot de passe) utilisent une validation stricte (ex: `Zod` + `React Hook Form`) affichant des messages d'erreur rouges typés "ERREUR SYSTÈME".
- Navigation entièrement supportée au clavier (attributs `aria-label`, gestion du focus visible avec des `outline` néon).
